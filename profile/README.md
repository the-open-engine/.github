# The Open Engine

We build open-source tools for coding agents, because AI should be free.

[theopenengine.com](https://theopenengine.com/?utm_source=github&utm_medium=org-profile&utm_campaign=org) · [Research blog](https://zeroshot.sh/blog/?utm_source=github&utm_medium=org-profile&utm_campaign=org)

## Projects

**[zeroshot](https://github.com/the-open-engine/zeroshot)** is a multi-agent orchestration engine that keeps coding agents from grading their own work. You define the graph, from implementation through independent review, testing and repair, and the engine enforces it. MIT licensed, runs locally or on zeroshot Platform.

[zeroshot.sh](https://zeroshot.sh/?utm_source=github&utm_medium=org-profile&utm_campaign=org) · [Docs](https://zeroshot.sh/docs/)

**[Opcore](https://github.com/the-open-engine/opcore)** checks a coding agent's edits as it works and tells it the file, location and rule to fix. Apache-2.0 licensed.

[Docs](https://the-open-engine.github.io/opcore/)
